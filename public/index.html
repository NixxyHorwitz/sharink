📥 Unduh Ekstensi Browser (.zip)
📖 3 Langkah Cepat Pasang di Browser
  1. Klik tombol unduh di atas, lalu ekstrak file .zip di laptop.
  2. Buka chrome://extensions atau edge://extensions di browser.
  3. Nyalakan Developer mode di pojok kanan → klik Load unpacked → pilih folder yang diekstrak tadi. Selesai!
