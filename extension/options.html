Pengaturan Sharink

Konfigurasi server relay dan preferensi penerimaan link

- Render / Local: Gunakan format WebSocket, misal wss://sharink-app.onrender.com atau ws://localhost:3000.
- Vercel: Gunakan URL Vercel Anda, misal https://sharink-app.vercel.app.

Nama ini akan muncul pada notifikasi perangkat penerima saat Anda mengirim link.

💡 Tips & Pintasan Cepat

  • Pintasan Keyboard: Tekan Alt + Shift + S kapan saja untuk langsung mengirim tab aktif saat ini tanpa membuka popup!
  • Klik Kanan (Context Menu): Klik kanan pada halaman atau link mana pun → pilih "Kirim Halaman / Link via Sharink".
  • Kompatibilitas Mobile: Buka web companion di browser HP Anda dengan pair code yang sama untuk saling kirim link PC ↔ HP!
